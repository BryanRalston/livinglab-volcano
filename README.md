# Kitchen Volcano — Living Lab

Phone AR science table: place a bowl-scale baking-soda volcano, pour soda then vinegar, read why, answer one quiz.

Dinosaur table (`/dinos/`): keyed imagine2 plate. Place the still, then Play. T. rex and Triceratops are on the table with a pterosaur; the flyer is not a dinosaur.
